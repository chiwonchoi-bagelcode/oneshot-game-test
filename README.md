# 보리의 폐품 로켓 대소동 (Junk Rocket Ruckus)

장난꾸러기 로켓 천재 **보리**가 폐품으로 만든 로켓을 조종해 엉뚱한 목표를 부수는 **세로형 모바일 물리 장난 게임**입니다.
캐릭터와 사물은 리틀빅플래닛풍의 펠트·골판지·뜨개 질감 3D 모델이고, 비행과 충돌은 2D 측면 공간에서 진짜 물리로 계산됩니다.

- 렌더링: [three.js](https://threejs.org) (절차적 크래프트 텍스처, 소프트 그림자, 블룸)
- 물리: [planck.js](https://piqnt.com/planck.js/) (Box2D 계열 2D 강체 물리)
- 사운드: Web Audio로 실시간 합성 (효과음·배경음악 에셋 없음)
- 빌드: Vite + TypeScript, 외부 이미지/모델 에셋 0개

## 실행

```bash
npm install
npm run dev          # http://localhost:5173 (휴대폰은 같은 Wi‑Fi에서 표시되는 Network 주소로)
npm run build        # dist/ 정적 빌드
npm run build:single # dist-single/index.html 한 파일짜리 빌드
npm run ci           # 타입 검사 + 단위 시험 + 출시 빌드 검사 + E2E 전체(정상 입력)
```

글꼴(Jua)은 번들에 포함되어 오프라인에서도 같은 화면이 나옵니다.

데스크톱 브라우저에서는 화면이 세로 비율로 레터박스됩니다. 마우스 드래그 = 손가락 드래그이고, 방향키/WASD(가속하고 싶은 방향)와 Space(점프), Esc(일시정지)도 지원합니다.

## 조작

| 단계 | 조작 |
| --- | --- |
| 발사 준비 | 화면 탭 → 보리가 크레이트에서 뛰어올라 공중제비를 돌고 널뛰기 반대편을 내려찍습니다. |
| 내려찍기 직전 | 노란 링이 초록으로 바뀔 때 다시 탭하면 **완벽한 내려찍기** — 발사 속도와 보너스가 올라갑니다. |
| 자동 상승 (약 2초) | 연료 소모 없이 안전하게 솟아오릅니다. 이때 드래그하면 상승 방향을 미리 틀 수 있습니다. |
| 비행 | **엄지 하나로 드래그**: 끌어당긴 방향으로 연료가 분사되고 로켓은 그 반대로 가속합니다. 손을 떼면 관성으로 날다가 중력에 떨어집니다. |

조작감은 "순간 이동"이 아니라 **추진과 관성**을 다루도록 설계했습니다.

- 로켓은 스틱 방향이 아니라 **자기 기수 방향으로만** 추력을 냅니다. 기수가 목표 방향으로 회전하는 데 시간이 걸리고(선회 속도·각가속도 제한), 크게 어긋나 있으면 추력이 줄어듭니다.
- 엔진은 즉시 최대 출력이 나지 않고 **스풀업**됩니다(엔진마다 다름). 다시 점화하는 순간 작은 "툭" 하는 반동이 있습니다.
- 날개가 공기를 물어 **옆미끄러짐을 서서히 잡아주고**(그립), 손을 떼면 기수가 다트처럼 진행 방향을 따라갑니다.
- 연료가 탈수록 로켓이 가벼워집니다.

## 게임 구조

### 무대 3개 — 통로가 아닌 열린 디오라마

| 무대 | 목표 | 공략법(발견 배지) |
| --- | --- | --- |
| 1. 뒷마당 대소동 | 심술 영감의 황금 노움 | 💥 정면 돌파 · 🪵 전망대 다리 부수기 · 🪴 매달린 무쇠 화분 떨구기(밧줄 끊기) · 🎆 압수된 불꽃놀이 상자 터뜨리기 |
| 2. 교장쌤 생일파티 | 교장쌤의 3단 케이크 | 💦 파티방 스프링클러 유리 밸브 · 🎂 와르르(삐걱대는 테이블 다리 / 샹들리에 줄) · 🎆 축포 상자 폭발 · 💥 무거운 케이크 드릴/압력솥 돌격 |
| 3. 축제의 하늘 | 시장님의 홍보 비행선 | 🎇 "절대 누르지 마시오" 축제 대포 · 🎯 비행선 꼭대기 밸브 정밀 저격 · 🔥 스프레이 토치로 불붙이기 · 💥 드릴로 고무 외피 관통 |

목표는 시작할 때 카메라가 날아가며 명확히 보여주지만, **해결법은 정해두지 않았습니다.** 판정 규칙(`docs/spec-core.md` §4): 로켓이 직접 부수면 정면 돌파, 부서진 것이 받치던 물건은 그 원인을 물려받고, **처음 움직이게 만든 연쇄가 공을 가져갑니다**(바닥·벽 같은 고정 구조물은 원인을 퍼뜨리지 않음). 결과 화면·배지·보상·소문은 같은 원인을 씁니다. 무대 목록에는 아직 못 찾은 공략이 `?`로 남고, 한 번 성공하면 다른 공략의 "소문"이 하나씩 공개됩니다.

**무대2는 남의 집 실내 난장판입니다.** 운동장 옆 집 창문 너머로 평화로운 생일파티가 보이고, 큰 창문·현관·천창·오른쪽 창 중 어디로든 침입해 축포·스프링클러·샹들리에·피냐타·어항을 연쇄로 망가뜨린 뒤, 7초 동안 조종해서 **유유히 빠져나가면 퇴장 보너스**를 받습니다. 가족은 놀라서 뛰고 팔을 휘두릅니다(`docs/ad-cards.md`).

각 무대에는 목표 말고도 엉뚱한 반응이 많습니다: 소화전 → 물기둥(위로 밀어주는 상승기류), 자판기 → 때리면 병뚜껑, 박 터뜨리기, 종 → 댕! 하고 동전, 송풍기, 트램펄린, 회전하는 관람차, 제트기류, 우주 위성 등.
지하 터널, 아이 방, 개집, 온실, 생일파티 집의 1층·파티방·다락방, 구름 섬, 우주 등 **한 번의 연료로는 다 못 보는 넓이**로 만들었고, 곳곳의 **톱니바퀴(무대당 6–7개)** 와 연료통이 "저쪽엔 뭐가 있을까"를 자극합니다.

### 충돌 · 파괴 규칙

- 모든 물건은 재질(골판지·나무·유리·벽돌·금속·도자기 …)별 강도를 가집니다.
- 로켓이 부딪히는 순간 `속도 × 유효질량 × 노즈 배율`을 계산해 강도를 넘으면 **그대로 뚫고 지나가고**(속도를 일부 잃음), 못 넘으면 튕기면서 내구도가 깎입니다.
  → 가벼운 로켓은 피해 다녀야 하던 벽을, 무겁고 강한 로켓은 그냥 뚫고 달립니다.
- 떨어지는 물건·파편·폭발·물·불도 같은 규칙으로 서로를 부숩니다(연쇄 반응).

### 차고 — 개조와 연구

비행에서 모은 **병뚜껑(돈)** 과 **톱니바퀴(부품)** 로 5개 슬롯의 부품을 연구·장착합니다. 숫자만이 아니라 가능한 공략이 바뀌도록 했습니다.

| 슬롯 | 부품 | 특징 |
| --- | --- | --- |
| 동체 | 페트병 / 페인트 통 / 압력솥 | 날씬·가벼움 ↔ 튼튼·무거움(돌파력↑, 좁은 틈 통과 불가, 강한 엔진 필요) |
| 엔진 | 콜라 멘토스 / 스프레이 토치 / 소화기 부스터 | 토치는 나무·밧줄·비행선에 **불을 붙이고**, 소화기는 불을 끄고 물건을 날려버림 |
| 연료통 | 우유팩 / 보온병 / 생수통 | 탐험 거리 ↔ 무게(연료가 줄수록 가벼워짐) |
| 노즈 | 고깔모자 / 냄비 투구 / 용수철 권투장갑 / 전동 드릴 | 정면 방어, **부수지 않고 세게 밀치기**, 벽돌도 뚫는 관통 |
| 날개 | 골판지 / 우산 / 피젯 자이로 | 손을 떼면 **활공**, 칼같은 선회와 접지력 |

324개 조합 중 추력비 1 미만(무거운 동체 + 약한 엔진)인 57개는 출격할 수 없고, 이유와 함께 "가볍게 고쳐줘"(보유 부품만 쓰는 최소 수정)를 제안합니다. 부품 사전: `docs/parts.md`.

### 부딪힐 것 vs 통과하는 배경

부딪히는 물체는 충돌 경계 그대로 **잉크 윤곽선**, 깨지는 물체는 **바느질 점선**(맞으면 금이 감), 작동 장치는 **깜빡이는 주황 점선**입니다. 배경은 안개색으로 흐리고 그림자가 없으며, 잔해·물·코인은 윤곽선이 없습니다. 실내 앞벽은 다가가면 투명해집니다(`docs/visual-contract.md`).

## 코드 구조

```
src/
  app.ts               화면 전환, 메인 루프, 자동 화질 조절, 설정·저장 안내
  core/                입력(플로팅 조이스틱), Web Audio 합성기, 저장(검증·백업), 로컬 계측, 수학(시드 난수)
  data/                부품 정의·스탯 계산, 무대 1–3 레벨 스크립트
  game/
    world.ts           planck 월드 + 엔티티, 관통 판정, 파괴/파편, 연쇄 원인 추적,
                       물·불·폭발·밧줄·바람·픽업 시스템
    rocket.ts          로켓 조종 모델(선회·스풀·추력·그립·활공) + 배기 이펙트
    flight.ts          한 판의 흐름: 인트로 → 널뛰기 발사 → 자동 상승 → 비행 → 결과
    level.ts           레벨 작성용 빌더 API + 정적 메시 병합
    garage.ts          타이틀/차고 3D 작업실
  render/              렌더러·후처리, 절차적 텍스처, 재질, 이펙트, 3D 모델(아이·로켓·소품)
  ui/                  DOM HUD·메뉴·설정·결과 화면(모달 초점 관리)
  dev/                 시험 빌드 전용: 정상 입력 훅, 성능 오버레이, 스트레스 무대
tests/                 단위 시험(vitest)    e2e/  Playwright 시험    docs/  명세·승인 매트릭스
```

## 품질 검증

- 출시 체크리스트 v3 대응 현황: **`docs/approval-matrix.md`** (항목별 상태와 근거, 사람·기기·스토어가 필요한 항목은 "검증 대기").
- 명세: `docs/spec-core.md`(상태·입력·원인·물리), `docs/spec-save.md`, `docs/spec-telemetry.md`, `docs/visual-contract.md`, `docs/perf-budget.md`, `docs/economy.md`, `docs/parts.md`, `docs/ad-cards.md`, `docs/qa-plan.md`.
- 자동 시험은 **정상 입력**으로만 진행합니다: 시험 빌드(`npm run build:test`)에만 들어가는 `src/dev/testhooks.ts`가 실제 `PointerEvent`를 손가락 위치의 요소에 보내 로켓을 조종하고, 시간만 60 Hz 고정 스텝으로 넘깁니다. 순간이동·상태/재화 주입은 하지 않으며, 출시 번들에 훅이 없는지 `npm run check:release`가 검사합니다.
- 결과: 12개 공략·20개 톱니 전부 발사부터 정상 입력으로 달성, R-01~R-11 회귀, 저장 손상 복구, 최대 난장판 스트레스 예산(그리기 ≤260, 잔해·물·파티클 상한).
- 성능 측정: 시험 빌드 주소에 `?perf`를 붙이면 FPS·p95/p99·그리기 호출·물체 수 오버레이가 나옵니다.
