# 충돌 물체 vs 배경 시각 계약 (Q-CI)

> 상태: **구현 확인**(코드·스크린샷) / **검증 대기**: 처음 보는 사용자의 "부딪힐 것/통과할 곳" 예측 대조(Q-CI-07), 실기기 작은 화면, 색각 차이 교차 확인.
> 코드: `src/render/contact.ts`, `src/game/world.ts`(`attachContact`, `syncBatches`), `src/game/level.ts`(`finalize`, `cutaway`, `sign`, `putInPlane`).

## 역할 사전 (Q-CI-02)
| 역할 | 데이터 | 외형 규칙 (색 하나에 의존하지 않음) |
|---|---|---|
| 단단한 물체 (부딪힘, 안 깨짐) | 정적/동적 엔티티, `breakable=false` | 충돌 경계 그대로 **연속 잉크 윤곽선**(두께 ≈0.17 m), 채도 그대로, 그림자 |
| 깨지는 물체 | `breakable=true` | **바느질 점선 윤곽선** + 피해에 따라 **금 2단계**(70 %·34 % 체력) |
| 작동 장치 | `role:'device'` (축포 상자, 밸브, 소화전, 스프링, 자판기, 종, 대포 버튼) | **주황 점선 + 맥박**(형태·움직임으로도 구분) |
| 통과 수집물 | 병뚜껑·톱니·연료통 | 윤곽선 없음, 회전·반짝임, 획득한 톱니는 반투명 유령 |
| 로켓과 안 부딪히는 잔해·물·입자 | `debris`, `water`, 파티클 | 윤곽선 없음, 작아지며 사라짐(잔해 4.5~7 s, 유리 1.2~2.2 s) |
| 배경 | 플레이 평면 뒤(z ≤ −1.5) 장식 | **안개색으로 흐림·채도 감소**, 그림자 없음 |
| 안내판 | z −1.7, 흐림 없음 | 가는 기둥, 윤곽선 없음 |

## 규칙
- 윤곽선은 물리 충돌체를 만든 **같은 숫자**로 그린다(사각형·원·지형 다각형). 보이는 경계 = 충돌 경계(Q-CI-03).
- 깨진 물체는 몸체·윤곽선이 함께 사라진다(보이지 않는 벽이 남지 않음). 창문을 깨면 그 자리는 실제로 통과된다.
- **플레이 평면 감사**: 충돌체 없이 플레이 평면(−1.5 < z < 1.5)에 놓인 장식이 있으면 `builder.planeAudit`에 기록된다. 모든 무대 0건을 E2E 상태로 확인(`state().planeAudit`).
- 실내 앞벽(`cutaway`)은 멀리서는 집처럼 보이고 로켓이 7 m 안으로 오면 유령(10 %)으로 사라진다(Q-CI-05). 충돌체가 아니다.
- 저품질 모드도 윤곽선·금·흐림 규칙은 같다(블룸·그림자 해상도만 낮춤, Q-CI-04/Q-PF-08).
- 성능: 윤곽선은 역할별 한 번의 그리기, 금은 인스턴스 두 번(`docs/perf-budget.md`).

## 남은 일
- 사용자 관찰로 오인 목록을 만들고 아트·충돌체·배치를 고치는 반복(Q-CI-07) — 사람 필요.
- 최대 난장판에서 연기·파편이 윤곽선을 가리는 정도 실기기 확인(Q-CI-08).
