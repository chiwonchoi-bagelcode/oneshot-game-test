# 광고 경험 카드 (Q-AH-01)

> 광고는 실제로 할 수 있는 경험만 보여준다(Q-AH-09). 각 카드의 장면은 같은 빌드·정상 입력으로 재현되며 재현 시험을 함께 적는다.
> 상태: **구현 확인(게임 안 흐름·재현 시험)** / **검증 대기**: 광고 영상 제작, 시청 기대·클릭·설치 가설 검증(Q-AH-10).

## AH-1 교장쌤 생일파티 (무대2) — 대표 훅
| 단계 | 게임 안 실제 내용 | 코드 / 시험 |
|---|---|---|
| 발견할 일상 | 운동회 날 운동장 옆 집, 창문 너머 따뜻한 조명 아래 케이크·선물·풍선·가족이 박수 치는 평온한 생일파티 | `src/data/stage2.ts` buildHouse, 카메라가 접근 시 집을 함께 잡음(`flight.ts` updateCamera) |
| 침입 | 큰 파티 창문(유리), 현관문(나무), 지붕 천창, 오른쪽 창, 1층 유리문 — 어디로 들어갈지 고른다 | `e2e/stage2.methods.spec.ts`(창문·현관·천창·오른쪽 창 경로 모두 사용) |
| 가장 재미있는 연쇄 | 축포 상자 폭발 → 테이블·케이크·선물 날아감 / 스프링클러 밸브 → 물바다 / 샹들리에 줄 → 와르르 / 테이블 다리 → 케이크가 계단 구멍으로 추락 / 피냐타 → 사탕 비 / 어항 깨짐 → 물 | 같은 spec의 boom·water·topple 테스트 |
| 공간의 반응 | 가족이 놀라 뛰고 팔을 들며 "어머나!", 케이크가 망가지면 "내 케이크…!!" (부상 표현 없음) | stage2.ts 가족 반응 애니메이션 |
| 퇴장 | 성공 뒤 7초 동안 조종 유지 → 창문으로 유유히 빠져나가면 "유유히 퇴장!" 보너스 | spec boom 테스트가 `escaped=true`, `escapes=1` 확인 |
| 정산 규칙 | 퇴장은 보너스(필수 아님), 퇴장 중 파손은 성공 유지·보너스 없음 | `docs/spec-core.md` §2 |

촬영 추천 컷(15초): ① 바깥에서 불 켜진 창(0~3 s) ② 널뛰기 발사·창문 와장창(3~6 s) ③ 축포 폭발·케이크 날아감·가족 놀람(6~11 s) ④ 창문으로 빠져나오며 "유유히 퇴장!"(11~15 s).

## AH-2 할아버지네 노움 (무대1) — 보조
일상: 할아버지 마당의 황금 노움과 전망대. 침입: 마당 울타리·땅굴·온실 유리. 연쇄: 전망대 다리 → 붕괴 / 매달린 무쇠 화분 / 압수한 불꽃놀이. 퇴장: 마당 밖으로. 시험: `e2e/stage1.methods.spec.ts`.
※ 실내 침입형 장면은 아니다(야외 사유지). 실내 카드는 AH-1이 담당.

## AH-3 시장님 홍보 비행선 (무대3) — 보조
일상: 축제 하늘의 홍보 비행선 "시장님 최고~". 연쇄: 축제 대포 버튼 / 꼭대기 공기 밸브 / 토치로 불붙이기 / 드릴 돌파. 시험: `e2e/stage3.methods.spec.ts`.

## 하지 않는 것
- 게임에 없는 드론·전용 연출·강제 해금 장면. 실제 사람 부상 묘사.
